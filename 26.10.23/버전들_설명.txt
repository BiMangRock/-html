■ 버전 확인법
- engine.js 맨 위 `const VERSION = 'v25';` 한 줄이 기준입니다. 버전을 올릴 때는 이 줄만 고칩니다.
- vNN.html 안에 내장된 엔진에도 같은 VERSION 줄이 있고, 화면 제목 옆 배지에 표시됩니다. (engine.js 와 html 의 VERSION 이 같아야 합니다)
- node analyze.js 를 돌리면 결과 맨 위에 "##### v25 · 날짜 · 봇 · 판수 #####" 가 찍히고, analyze.js 가 있는 폴더의 분석결과.txt 맨 아래에 자동으로 이어붙습니다. (덮어쓰기 아님)
- 저장을 끄려면 node analyze.js 1500 rule2 --no-save

■ 파일 구조 (v25부터: 엔진 내장 방식)
- 각 vNN.html 은 엔진(카드풀·규칙·봇)을 안에 통째로 가지고 있습니다. html 하나만 열어도 동작하고, 그 버전의 규칙이 그대로 보존됩니다. (폴더 위치 신경 쓸 필요 없음)
- engine.js 는 "작업용 최신 엔진"입니다. analyze.js 가 이 파일을 읽어 분석합니다.
- 새 버전을 낼 때: engine.js 를 고치고(VERSION 포함), 그 내용을 새 vNN.html 의 <script id="engine"> 안에 그대로 복사해 넣습니다. (두 곳이 어긋나지 않게 제가 복사해서 드립니다)
- 카드·규칙·봇을 바꾸면 engine.js 와 새 html 을 같이, 화면만 바꾸면 html 만 받으면 됩니다. engine.js 가 바뀌지 않았으면 engine.js 는 안 줍니다.
- 어긋남 주의: v23.html, v24.html 은 <script src="engine.js"> 로 엔진을 불러 쓰던 방식이라, 열면 항상 현재 engine.js 의 규칙으로 돌아갑니다. (옛 규칙이 보존되지 않음)

■ v25 (최신) — 변경된 점
0) 구조 변경: 엔진을 html 안에 다시 내장했습니다. (위 "파일 구조" 참고) engine.js 와 v25.html 안의 엔진은 글자 단위로 동일합니다.
1) 주문 지정 문제 수정 (v25.html — 화면 수정)
- 원인: 대상이 있는 카드인데 고를 수 있는 대상이 딱 하나뿐이면, 선택 단계 없이 바로 발동되고 있었습니다.
  침묵(도발·보호막 있는 적 하수인만 대상)과 치유의 빛(내 영웅·내 하수인만 대상)은 대상이 하나뿐인 경우가 잦아서 "지정이 안 된다"처럼 보였습니다.
- 수정: 대상이 있는 카드는 후보가 하나뿐이어도 항상 "대상을 선택하세요" 상태로 들어가고, 대상을 직접 눌러야 발동합니다. (대상이 필요 없는 카드는 그대로 바로 발동)
  선택 중에 카드를 다시 누르거나 빈 곳을 누르면 취소됩니다. 후보가 0개면 기존처럼 "이 주문을 쓸 대상이 없습니다."
2) 발견은 항상 3장 중 선택 (engine.js)
- 피의 서약(비용 5 이상 발견)은 조건에 맞는 주문이 대폭발·공중활강 2장뿐이라 선택지가 1~2장이었습니다.
- 수정: 비용 범위 안의 주문을 먼저 무작위로 뽑고, 3장이 안 되면 범위에 가장 가까운(비싼) 주문으로 채워 항상 3장 중에서 고르게 합니다.
  지금은 피의 서약이 늘 대폭발·공중활강 + 4코 주문 1장(화염구/불의 비/사냥개 떼 중 무작위)을 보여 줍니다. 할인(-2)은 3장 모두에 적용됩니다.
- 주문 발견(범위 없음)과 불꽃 점괘(비용 3 이하)는 원래도 3장이었고 그대로입니다. 발견 후보는 항상 전체 주문풀에서 뽑습니다.
- 카드 문구는 그대로 "비용 5 이상 주문 1장을 발견합니다"입니다. 5 이상 주문이 3장 이상 생기면 이 보충 규칙은 자연히 쓰이지 않습니다.
검증: 발견 300회씩(주문 발견·피의 서약·불꽃 점괘) 모두 3장·중복 없음, 봇 대전 500판씩 오류 0.

■ 새 카드 상세 (v21~v24에서 추가)
- 피의 서약 (2코 주문): 마나 대신 생명력 2를 지불하고, 비용 5 이상 주문(대폭발·공중활강)을 포함한 3장 중 하나를 발견합니다. (5 이상이 3장 미만이면 가장 비싼 주문으로 채움) 발견한 주문은 비용이 2 줄고, 마나로 씁니다.
- 불꽃 점괘 (3코 주문): 대상에게 피해 2를 주고, 비용 3 이하 주문을 발견합니다. (할인 없음. 비용 3은 임의로 정함)
- 날쌘 척후병 (2코 하수인, 1/3 속공): 낸 턴에 하수인만 공격할 수 있습니다. (이름·비용은 임의로 정함. v21에서는 돌진이었으나 v22에서 속공으로 수정)
- 사냥개 떼 (4코 주문): 속공 3/1 「질주 사냥개」 3마리 소환. (v24)
- 공중활강 (7코 주문): 속공 1/1 「활강병」으로 전장을 가득 채움. 이번 턴에 모두 죽으면 같은 수만큼 다시 소환. (v24)
- 생명력 비용 카드는 체력이 지불액 이하이면 낼 수 없습니다. 카드 비용 숫자 옆에 ♥가 붙고, 문구에 "마나 대신 생명력 N 지불"이 표시됩니다.
- 봇은 생명력 비용 주문을 체력이 (지불액 + 10) 초과일 때만 냅니다.
