봇끼리 대전시켜서 밸런스를 보고 싶다 → 별도 파일이 필요 없습니다. 이미 selfPlay가 있어서 브라우저 콘솔에서 돌릴 수 있고, 카드 승률 통계 같은 건 거기에 붙이면 됩니다.
봇이 플레이하는 걸 화면에서 구경하고 싶다 → 같은 파일에 관전 모드 버튼을 하나 추가하면 됩니다. 지금은 내 자리(MY)가 사람 입력을 기다리는데, 그 자리에도 봇이 결정하게 연결하는 정도입니다. 기존 화면과 애니메이션을 그대로 쓸 수 있어요.
내가 만든 더 똑똑한 AI(또는 Claude 같은 LLM)를 붙이고 싶다 → 파일은 그대로 두고 BotPlayers에 새 봇을 하나 등록하면 됩니다. 봇이 받는 입력은 view(상태)와 view.legal(가능한 행동)이라서, 외부 AI에게 넘기기도 쉬운 형태입니다.
파이썬 등 외부 프로그램에서 학습시키거나 대량 시뮬레이션을 돌리고 싶다 → 이때만 규칙 부분을 별도 파일(JS나 Node)로 분리하는 게 좋습니다. 브라우저 없이 훨씬 빠르게 돌릴 수 있어요.


1. 봇끼리 대전 (밸런스 테스트)

봇 둘이 화면 없이 1000판을 순식간에 돌립니다.
결과는 "A카드 쓰면 승률 62%" 같은 숫자로만 나옵니다.
목적: 카드가 너무 센지 약한지 확인
비유: 선수들 몰래 연습경기 1000번 돌려서 기록만 보는 것

2. 관전 모드

화면에서 봇 두 명이 싸우는 걸 직접 눈으로 봅니다. 카드 내고 공격하는 애니메이션도 그대로 나옵니다.
목적: 구경, 봇이 어떻게 두는지 확인
비유: 유튜브로 프로게이머 경기 보는 것

3. 더 똑똑한 AI 붙이기

지금 상대 봇(rule)은 정해진 규칙대로 두는 단순한 봇입니다. 이걸 더 잘 두는 AI로 교체합니다.
목적: 상대를 더 강하게 만들기
비유: 쉬움 난이도 상대를 어려움 난이도 상대로 바꾸는 것

4. 외부 프로그램에서 대량 학습

게임 규칙만 따로 빼서 파이썬 같은 프로그램이 직접 수십만 판을 돌리고 학습합니다.
목적: AI를 직접 훈련시키기
비유: 선수를 훈련시키는 전용 훈련장을 따로 짓는 것
	화면	사람이 보나	목적
1	없음	숫자만	밸런스 확인

2	있음	구경	재미, 확인
3	있음	내가 플레이	더 강한 상대
4	없음	안 봄	AI 학습

어떤 걸 고르면 될까요?

카드 밸런스가 궁금하다 → 1번
봇이 노는 걸 보고 싶다 → 2번
게임이 너무 쉬워서 상대를 강하게 하고 싶다 → 3번
AI 개발 자체가 목표다 → 4번







A. 규칙 봇 개선

지금 규칙 봇은 "비싼 카드부터 내고, 약한 하수인부터 공격"이 전부입니다.
여기에 "체력이 위험하면 방어 우선", "죽일 수 있으면 영웅 대신 하수인 처리" 같은 판단을 추가합니다.
장점: 가장 쉽고 빠름 / 단점: 사람이 규칙을 계속 생각해야 함

B. 앞을 내다보는 봇 (탐색 / MCTS)

행동 후보마다 게임을 복사해서 끝까지 가상으로 여러 번 돌려보고, 이기는 비율이 가장 높은 행동을 고릅니다.
배우신 몬테카를로와 같은 아이디어입니다. 이 게임은 상태 복사와 적용이 이미 지원되어서 붙이기 좋습니다.
장점: 학습이 필요 없음 / 단점: 상대 손패를 모르니 추측이 필요하고, 턴마다 계산 시간이 듦

C. 강화학습으로 훈련한 봇

4번에서 학습시킨 결과(숫자 덩어리)를 파일에 넣고, 그걸 읽어서 행동을 고릅니다.
이게 원래 "상급"이라고 적어둔 의도입니다.
장점: 실행은 빠름 / 단점: 학습 과정이 먼저 필요 (4번 작업)




A카드 쓰면 승률 62%" 같은 카드별 통계는 현재 함수에 없습니다. 카드별로 보려면 덱을 한 장만 바꿔서 여러 번 돌려 비교하는 식으로 확장해야 합니다. 원하시면 그 기능을 추가한 버전을 만들어 드릴게요.
